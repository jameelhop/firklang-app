# firklang — installerbar webudgave

Dette repo indeholder **kun det byggede output** af firklang-appen, så den kan
serveres via GitHub Pages. Kildekoden ligger et andet sted.

Åbn appen: https://jameelhop.github.io/firklang-app/

På telefonen kan den installeres til hjemmeskærmen og virker derefter offline.
